# Roadmap triển khai — bắt đầu từ giai đoạn 6

## M0 — môi trường, baseline và quyền
- Tạo branch `research/aot-localization`; lưu hash, package/version, min/target SDK, ABI, signing cert, permission, list entry. Kiểm tra điều kiện quyền sửa và phân phối. Chạy verify_inputs.
- Cài Android SDK build-tools/platform-tools, Java theo requirement, jadx/apktool, Python/Node/Playwright nếu cần; dùng nguồn chính thức. Kiểm tra phiên bản, đường dẫn và log. Thiết lập máy Android test hoặc emulator phù hợp ABI; kiểm tra bản gốc trước để ghi screenshot/video cho từng màn hình, locale và trạng thái. Không gửi lệnh motor nguy hiểm; tháo motor hoặc kê bánh khi test.
- Đọc skill fingerprint, không chỉ dùng jadx cho Flutter. Không chạy script tải về khi chưa review. Cài AOT analyzer thích hợp với Dart snapshot thực; Blutter là ứng viên, không coi support ARM32 hay Dart 3.12.2 là mặc định. Có thể cần Dart VM build khớp snapshot, symbols/engine revision và công cụ disassembly (Ghidra/IDA/radare2 tùy quyền/license). Ghi tool version, commit, flags và lỗi. Không thay `libflutter.so` tùy tiện.

## M1 — tìm đường đi locale thực tế (gating)
- Trích ELF cả hai ABI từ APK gốc, đọc snapshot header/build ID, inspect architecture/sections, decode object graph và code references bằng parser tương thích. Kiểm tra cả one-byte/two-byte strings và canonical objects. CSV chỉ là anchor.
- Truy UI Settings → Language list → callback → state manager → persistence → rebuild; xác minh locale IDs, fallback, supportedLocales, translator lookup (Flutter generated localization/map/logic riêng), current locale và các menu strings. Xác định chức năng nào dùng localization framework và chức năng nào hardcode hoặc ảnh. Dùng debugger/runtime traces hợp pháp trên máy test nếu cần, không bypass bảo vệ.
- Truy chọn ảnh locale (vd `remote_en.png`, `instruct_de.png`, `state_ru.png`), `AssetManifest.bin`, `FontManifest.json`, và WebView init/JS channels. Xác minh đường đi đổi language qua restart.
- Deliver `docs/aot-map.md` có địa chỉ/ABI/tool/reference có bằng chứng, bảng locale gốc từ runtime, screenshot baseline, phương án sửa theo đối tượng/logic thực hoặc source hợp pháp. Nếu chưa có, DỪNG ở gate, không patch offset thô.

## M2 — proof of concept menu native
- Ưu tiên sửa source nếu lấy được hợp pháp; nếu chỉ AOT, đánh giá phương án can thiệp tối thiểu có thể build/reproduce cho hai ABI, tính đúng snapshot layout, string representation, object references, relocations, GC/encoding và dispatch. Không coi AOT parser là compiler/decompiler đầy đủ. Không ghi đè locale cũ bằng locale mới.
- Thêm lựa chọn thử nghiệm th vào Settings chính, label `ภาษาไทย`, giữ tất cả locale gốc. Verify chuyển language, fallback, app restart, navigation, không crash, không hỏng lưu chương trình. Nếu chỉ overlay/dịch màn hình hoặc WebView select thì chưa đạt menu native.
- Chỉ khi có PoC chạy trên Android mới nhân ra en/th/lo/km. Nếu công cụ chỉ support một ABI, không tự bỏ ABI kia; ghi blocker và cần quyết định của chủ dự án nếu có tradeoff.

## M3 — toàn bộ bản dịch và tài nguyên
- Inventory dựa trên màn hình/runtime + call sites: startup, home, Settings/Language, connect/pair/scan/disconnect, remote, gravity, path, voice nếu có, motor/speed/direction, programming, save/open/rename/delete, help/instructions, permissions, errors, empty/loading, confirmation. Xác minh feature thực tế; ghi nguồn từng key và screen ID. Không dịch internal ID, command payload, preference key, tên thiết bị/biến và user content.
- Dùng schema `key,source,context,en,th,lo,km,source_ref,review_status,screen_test`, đối chiếu glossary, placeholder `%1`, `%2`, format số, newline, plural, punctuation. Stage1/5 là draft; không đo coverage bằng số key candidate. Đánh dấu missing và native review; đối chiếu thuật ngữ điều khiển, stop/cancel, forward/reverse. English gốc giữ nguyên nếu đầy đủ.
- Tài nguyên ảnh: inventory thực tế toàn bộ asset chứa chữ, tạo các variant mới cùng kích thước/alpha/density, không chỉnh biểu tượng/chức năng. Kiểm tra text rendering với font Noto Sans Thai/Lao/Khmer hoặc font phù hợp có giấy phép; ghi license/attribution nếu bundle. Cập nhật asset registration đúng định dạng Flutter binary nếu cần; không giả AssetManifest JSON là tương đương. Test fallback và tất cả màn hình, không cắt glyph/combining marks/line height, Khmer shaping, scale, landscape/portrait, kích thước nhỏ.

## M4 — đồng bộ native và Blockly
- Một locale source-of-truth trong app, persist bằng cơ chế gốc nếu an toàn. Default/fallback phải giữ hành vi gốc, nếu locale không hỗ trợ fallback rõ ràng. Truyền locale vào WebView thông qua bridge đã xác minh, refresh label/UI nhưng bảo toàn workspace XML, ID, mutation, variables, user content. Tránh native/WebView độc lập. Có thể giữ select phụ chỉ khi phù hợp UI gốc, nhưng menu chính bắt buộc. Không đổi logic BLE.
- Stage3 tests giữ nguyên, mở rộng fixture XML cho loop, variable, procedure, motor và mọi biến thể HTML. So sánh commands hoặc trace trong test harness an toàn trước/sau, không gửi gói lệnh thử không hiểu. Kiểm tra load trước/sau đổi locale, existing projects, save/open, localStorage blocked, permission denied, reconnect, offline.

## M5 — build reproducible / ký / test
- Tạo patch có version, hash precondition, dry-run và reject khi không khớp APK. Tách source tự viết khỏi extracted/vendor files, không ghi đè bản gốc. Manifest, DEX, native library diff whitelist; giải thích từng thay đổi. Verify CRC, asset registration, APK alignment (stored native 16 KB khi applicable), official Android SDK `zipalign -c -P 16 -v 4 file.apk` và `apksigner verify --verbose --print-certs file.apk` (kiểm tra option theo build-tools version). Ký sau align bằng key local mới, không commit/pass secrets trong log. Cài bằng `adb install` trên thiết bị test sạch, đọc logcat, kiểm tra permission, app launch, tất cả locale. Chữ ký khác nên không cài đè gốc; backup trước, không gỡ app chính nếu chưa sao lưu. Kiểm tra ABI và Android versions tương thích, không tuyên bố support khi chưa test.
- Chạy toàn bộ `docs/ACCEPTANCE.md`, reviewer bản ngữ, test BLE thiết bị thật an toàn. Ghi version/build/hash, matrix test, screenshots, logs và known issues. Chỉ đặt tên final `PowerBox_2.1.1_Multilingual.apk` sau khi đạt tất cả gate; nếu chưa, đặt `TEST` rõ và không tuyên bố hoàn chỉnh.

## Các commit/mốc đề xuất
`docs: capture baseline` → `research: map native locale dispatch` → `feat: prove native locale selection` → `feat: add locale assets and translations` → `feat: synchronize Blockly locale` → `test: Android localization regression` → `release: verified multilingual build`. Mỗi phiên lưu báo cáo PASS/FAIL/BLOCKED/NOT RUN, hash và cách tái lập. Không cần dùng GitHub Actions cho APK proprietary nếu chưa được phép; có thể chạy local.
